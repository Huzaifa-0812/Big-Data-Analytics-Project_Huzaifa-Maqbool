This project demonstrates the implementation of core components of the Hadoop ecosystem, including Apache Sqoop, Pig, Hive, and HDFS. It covers the complete big data processing pipeline, starting from data ingestion from relational databases, transformation and analysis of large datasets, and finally structured storage for efficient querying.

The project includes:

Data import and export between MySQL and HDFS using Sqoop
Data processing and analytical operations using Apache Pig
Data warehousing concepts using Apache Hive (internal & external tables, partitioning)
File system operations using HDFS commands

Through this project, key big data concepts such as distributed storage, parallel processing, data transformation, and query optimization are implemented and demonstrated with practical examples.

This repository reflects hands-on experience in handling large-scale data and building scalable data processing workflows using Hadoop technologies.
